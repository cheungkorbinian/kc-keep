# KC KEEP · 本地说明

基于 Tiny Swords 素材的 2D 俯视生存 RPG。美术资源留在本地，不随代码仓库分发。

## 本地运行

在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 [本地游戏](http://127.0.0.1:8765/game/?v=90.1)。

## 默认操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 冲刺 / 武装静止时格挡 |
| 鼠标左键 | 选中目标行动 / 点地移动 |
| 鼠标右键 / E | 检查 |
| 空格 | 附近行动 / 添柴；Shift+空格烤肉 |
| F / J / R | 采集 / 攻击 / 进食 |
| C / K | 施放法术 |
| 1 / 2 / 3 | 选择火 / 冰 / 雷 |
| B | 水桶空时靠岸装水；有水时向鼠标位置泼水 |
| V | 在鼠标位置铺一格防火带（石头 1，范围 120） |
| X / Q | 拆除 / 切换形态 |
| Tab / I / T | 合成 / 背包 / 火把 |
| Esc | 暂停；暂停后再按一次保存并返回主菜单 |
| F5 / F9 | 保存 / 载入 |

顶部的「远征手册」和「设置 / 存档」打开时暂停游戏。常用按键可在设置中修改；底部快捷键和引导同步更新。

## v90.1 · 远征与消防更新

- **消防**：每颗火球最多点燃一格；燃烧 3 秒后才开始蔓延，最多距最初火源两格，全图同时最多 24 格。重复点燃不延长寿命。
- **灭火工具**：在手册中用木材 3、石头 2 制作水桶；一桶水可泼三次。冰法也能灭火，泼湿地面短时间内不会复燃。石质防火带不燃烧。
- **行动反馈**：标出鼠标选中的目标，提示靠近、工具要求及燃料已满。
- **第一夜引导**：收集木材、获取食物、添柴和度过夜晚。进度随存档保存，提示可关闭。
- **据点进阶**：在初始营地附近升级三次。每级增加 15 最大生命，并提高营地附近的恢复速度。后两级需要探索或击败区域首领；三级据点加击败红堡僭主完成远征。
- **世界保存**：记录采伐、矿石耗尽、地形变化、建筑与道具状态、地面掉落及已击败的地图初始敌人。保留火势、角色特性、工具耐久、烹饪进度和探索迷雾。
- **设置与备份**：音量、改键、引导开关、JSON 存档导出/导入。导入前保存当前进度并留一份本地备份；无效文件会被拒绝。

旧版 v1/v2 存档可载入。旧版未记录的资源变化无法补回；没有角色信息的 v1 存档使用 KC1。敌人当前行走位置和临时刷出的敌群不属于完整快照，会在载入后重新模拟。

## 验证

在仓库根目录运行：

```bash
node scripts/test-stability.cjs
node scripts/test-expedition-ui.cjs
```

第一套使用真实世界生成器与游戏函数检查保存、消防、采集、据点进阶和旧存档；第二套检查设置、改键、音量及面板焦点。
