# KC KEEP · 本地说明

基于 Tiny Swords 素材的 2D 俯视生存 RPG。美术资源留在本地，不随代码仓库分发。

## 本地运行

在仓库根目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 [本地游戏](http://127.0.0.1:8765/game/?v=90.4)。

## 默认操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 冲刺 / 武装静止时格挡 |
| 鼠标左键 | 选中目标行动 / 点地移动 |
| 鼠标右键 / E | 检查 |
| 空格 | 附近行动 / 添柴；Shift+空格烤肉 |
| F / J / R | 采集 / 攻击 / 进食 |
| C / K | 施放法术 |
| 1 / 2 / 3 | 选择火 / 冰 / 雷 |
| B | 水桶空时靠岸装水；有水时向鼠标位置泼水 |
| V | 在鼠标位置铺一格防火带（石头 1，范围 120） |
| X / Q | 拆除 / 切换形态 |
| Tab / I / T | 合成 / 背包 / 火把 |
| M / Shift+M | 世界地图与路标 / 使用舆图卷 |
| Esc | 暂停；暂停后再按一次保存并返回主菜单 |
| F5 / F9 | 保存 / 载入 |

顶部的「远征手册」和「设置 / 存档」打开时暂停游戏。常用按键可在设置中修改；底部快捷键和引导同步更新。

## v90.1 · 远征与消防更新

- **消防**：每颗火球最多点燃一格；燃烧 3 秒后才开始蔓延，最多距最初火源两格，全图同时最多 24 格。重复点燃不延长寿命。
- **灭火工具**：在手册中用木材 3、石头 2 制作水桶；一桶水可泼三次。冰法也能灭火，泼湿地面短时间内不会复燃。石质防火带不燃烧。
- **行动反馈**：标出鼠标选中的目标，提示靠近、工具要求及燃料已满。
- **第一夜引导**：收集木材、获取食物、添柴和度过夜晚。进度随存档保存，提示可关闭。
- **据点进阶**：在初始营地附近升级三次。每级增加 15 最大生命，并提高营地附近的恢复速度。后两级需要探索或击败区域首领；三级据点加击败红堡僭主完成远征。
- **世界保存**：记录采伐、矿石耗尽、地形变化、建筑与道具状态、地面掉落及已击败的地图初始敌人。保留火势、角色特性、工具耐久、烹饪进度和探索迷雾。
- **设置与备份**：音量、改键、引导开关、JSON 存档导出/导入。导入前保存当前进度并留一份本地备份；无效文件会被拒绝。

旧版 v1/v2 存档可载入。旧版未记录的资源变化无法补回；没有角色信息的 v1 存档使用 KC1。敌人当前行走位置和临时刷出的敌群不属于完整快照，会在载入后重新模拟。

## 验证

在仓库根目录运行：

```bash
node scripts/test-stability.cjs
node scripts/test-expedition-ui.cjs
```

第一套使用真实世界生成器与游戏函数检查保存、消防、采集、据点进阶和旧存档；第二套检查设置、改键、音量及面板焦点。

## v90.2 · 玩家反馈修复

- 重生固定返回最初的据点南门，不再跟随最近营火。
- 单堆上限只影响显示，溢出的物品保留并拆为多堆；背包使用左右方向键翻页。
- 营火旁空格添柴、Shift+空格烤肉；烤制中也能添柴。
- 放缓环境降温，冬帽进一步减慢降温；暴风雪取消瞬间降温，只有低体温时才造成冻伤。
- 合成成套武装或击杀熊王永久解锁武装形态，死亡保留；旧存档按已完成任务恢复资格。
- 空格/F 优先拾取附近遗物和物品，点击遗物回收指定尸体，多次死亡留下的遗物可分别取回。J 仍为攻击。

旧版本已被截断的物品数量无法从现有存档还原。本次为本地更新。

## v90.3 · 导航、背包与存档

- 小地图用红色标记指出未回收遗物（含多次死亡留下的尸体）。
- 近距离行动提示按实际优先级显示拾取、遗物、添柴与 Shift+空格烤肉；鼠标目标标明左键。
- 冬季到来前 90 秒、暴风雪到来前 20 秒提醒备柴、冬帽和暖石；小地图显示临近冬季倒计时。
- 背包通常 15 格；已有背包或猪皮背包时按当前装备扩充至 19/21 格。每个物品堆叠占一格。新物品放不下时会留在地面，地面叠加数量可见。旧存档已经超过容量的物品保留，之后新增物品按空余格数处理。
- 设置面板显示自动与手动存档时间，可保存独立手动槽。读取手动槽须勾选替换确认，当前旅程会先保存到导入前备份。旧存档没有时间记录时显示为旧存档。

该版本目前只保存在本地，尚未推送线上。

## v90.4 · 远征目标与战斗提示

- 敌人近战蓄力显示红色范围，远程攻击显示瞄准方向；季节首领的特殊攻击先标出危险区域，再结算效果。
- 按 M 查看已探索的世界地图，左键在已探索区域设置路标，右键清除；小地图显示路标与方向。地图打开时游戏暂停。
- 远征目标完成后发放一次性奖励：营火燃料、舆图卷、暖石、永久生命上限或熟食；旧存档已完成的目标补发一次。
- 陨落时显示死因、附近威胁及遗物位置提示；最近一次记录也显示在远征手册。
- 初始营地增加练习木桩。完成三次近战、一次法术和武装形态格挡后，领取两份熟食。训练进度和奖励随存档保存。

本地更新尚未推送线上。
